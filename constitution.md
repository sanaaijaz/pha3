# Global Technology Constitution

## Phase III Requirements (Current Authority)

- **AI Chatbot**: Integrated AI assistant named "todo-agent" (see [agent_spec.md](file:///e:/phaselll/agent_spec.md))
- **Protocol**: MCP (Model Context Protocol) based tool execution
- **Statelessness**: Agent must be stateless, relying on MCP for data
- **Capabilities**: Conversational task management (add, list, update, delete, complete)

## Phase II (Baseline)
- Python REST API with FastAPI
- Neon Serverless PostgreSQL
- Next.js Frontend
- JWT Authentication

## Rules
- Authentication and Web frontend are standard
- AI/Agent features are now required as per Phase III spec
- MCP tools must be implemented for backend integration

This amendment preserves phase isolation and acts as the authoritative technology policy.
